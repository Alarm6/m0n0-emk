# ЕМК — Екатеринбургские металлические конструкции

Адаптивный сайт-каталог металлоконструкций с интерактивным опорным узлом. При прокрутке узел поворачивается, а гайки появляются и закручиваются по резьбе. До готовности сцены виден заголовок; затем плавно проявляются модель и меню.

## Запуск

Нужен Node.js 18 или новее. Установка пакетов и сборка не требуются:

```sh
npm start
```

Откройте http://localhost:3000. Для другого порта задайте переменную окружения `PORT`.

## Размещение

Папка `dist/` содержит готовый статический сайт. Её можно разместить на любом хостинге статических файлов. Публикуйте содержимое папки, сохраняя вложенные пути.

## Файлы

- `dist/index.html` — разделы и содержимое сайта.
- `dist/style.css` — адаптивная вёрстка.
- `dist/steel.js`, `dist/assembly.mjs` — 3D-сцена и сборка при прокрутке.
- `dist/loading.js` — открытие страницы после готовности сцены.
- `dist/assets/` — оптимизированные изображения, текстуры и SVG.
- `dist/vendor/` — локальная копия Three.js и лицензия MIT.
- `source-assets/` — исходные сгенерированные изображения.

Изображения и промпты описаны в `IMAGE-ASSETS.md` и `NEW-PRODUCTS.md`. Источники логотипов — в `COMPANIES-SOURCES.md`. Текстура окружения Studio Small 08 взята с Poly Haven: https://polyhaven.com/a/studio_small_08 (CC0).
